## What the baseline actually proves
- 41 immutable original live scenarios, 96 **synthetic shadow catalog candidates**, and 100 **QA-registered plan actions** are different counts. 90 distinct action IDs had completed/learned evidence at 02:15 UTC 2026-11-02, but do not equate action count with measured H6 uplift.
- 12 road cars share a collision-tested closed loop. The 3D view caps visible humans at 72; these are render slots, not a newly created resident population. Existing pet/animal records are sparse; do not fabricate ownership, medical outcomes or social relationships by adding meshes.
- ~140 street-tree positions are shared with pedestrian obstacles; changing them can invalidate walking. The initial density pilot adds **48 northern, non-collidable background tree silhouettes** in existing trunk/foliage instanced batches; existing roads, collision footprints and D1 stay unchanged.
- Scripted social scene library goes 22 → 26 authored short scene options; they are **not LLM dialogue, remembered personal ties or a measured increase in real conversation events**.

## Release ladder (each stage independently reviewed)
1. **V0 QA visual safety pilot** — Only static distant scenery and authored scripted social variety. No world writes, H6 treatment, agents or traffic count changes. Browser tests for desktop/mobile WebGL nonblank pixels, camera switch, visual occupancy and material/render-call limits. Monitor frame duration p50/p95 (Chrome performance trace), GPU memory proxy, draw calls, scene load and crash events. If p95 frame-time rises >15% or frames become blank on target devices, revert visual-only commit. This percentage is a proposed gate, not an observed measurement.
2. **V1 dynamic density** — Add at most +10–20% visible resident slots (72 → 80–86) behind a QA quality gate **only if real QA world already has those actors**. No spawn illusions, no policy backfill. Verify identity picking, resident position, camera occlusion, 60-second frame timing and phone throttling. Keep eco quality at current cap until measured. Do not increase hundreds of skinned meshes; use shared instanced crowd with distance LOD.
3. **V2 planted scenery + animals** — Only extend real decorative planters in reserved, no-collision footprints; distinguish visual ambient fauna from tracked animals/pets. Increasing genuine pets requires explicit owner/health/routine schemas, scenario events, collision/welfare tests, and QA evidence. Measure <10% draw-call and p95 frame-time regression (proposed acceptance criterion); use view frustum/distance LOD and capped mesh pools.
4. **V3 vehicles** — Proposed 12 → 14 → 16 car canary *only after* sweeping all route bends, fixed headway, swept vehicle footprint, pedestrian yielding, jam recovery, stop queue, day/night and mobile FPS. Do not add buses/metrolines on unvalidated road paths. Maintain traffic as visual ambience unless a genuine rider trip is evidenced.
5. **V4 social and conversation** — Expand authored scripts at genuine locations before increasing concurrency. Pair resident social plans only with both peers eligible, collocated and available, and settle familiarity only on completed matched plans. Track unique conversation events, real completed reciprocal ties, dialogue repetition, cooldown, visual speech clipping, social need outcomes and inference cost. Rate-limit and keep quiet hours; no PII in log aggregates.
6. **H6.1 shadow scoring** — Remain `XOM_H6_MODE=shadow-only` until an independently approved Ed25519 signed artifact + SHA, separate trusted public key and QA-only binding are installed. Require observed shadow evaluated count, paired agreement/mismatch, low/med/high uncertainty buckets, scorer errors and inference p50/p95/p99 with Worker version. No change to plans or training policy.
7. **H6.2 offline holdout benchmark** — Compare exact baseline on ordinary/stress/safety needs, day/night, cold-start, context freshness, diversity and real outcome reward. Require protected needs non-regression and positive ordinary holdout lower 95% confidence bound; reject cold-stress shared prior regressions. Synthetic 744 priors/96 candidates are not learned samples.
8. **H6.3 signed promotion decision** — Independently reviewed, signed, fail-closed gate with matching SHA/catalog, allowed QA cohort, expiry, rollback Worker version and proof from H6.1+H6.2.
9. **H6.4 QA control/canary** — Only after H6.3: fixed signed `neighbor-N` subset ≤5% of true residents, concurrent control, needs-guard fallback, model/arm eligibility. Compare matched completed real reward, arm coverage, action entropy, individual welfare, errors, CPU and latency across 24–72 hours; kill switch true by default.
10. **H6.5 gradual expansion** — 5% → 10% → 25% only with new independently signed gates, completed field data, holdout proof, no reward/welfare/diversity regression and an executable rollback plan. Each stage must be stoppable separately.

## Observability gates
- Cloudflare: Cron every 5 min, outcome/CPU-limit, 60-minute scheduled success; per-stage `pulse_stage` tick/social/learning p50/p95; HTTP 5xx, retries/duplicates, D1 state/commit failure, Worker version, bound D1 UUID, H6 flags and catalog SHA.
- D1: revision, turns, experiences, completed ticks, policy rows, learned arms, distinct actual completed `scenarioId`, per-scenario/hour reward, last committed time; separate visual-only counts. **No POST pulse** just to improve a metric.
- Frontend: WebGL context loss, first frame p50/p95, FPS p50/p95 on desktop/low-end phone, texture/geometry pools, draw calls, render resolution, three camera modes, long 5-minute session memory growth. Compare same fixed camera/scenario/time slice/viewport/device (not a one-off screenshot). Publish before/after raw summaries before changing budgets.
- Social: paired interactions per hour, distinct peers and topics, same-scene repetition, actual familiarity changes after completed plans, no fabricated ownership, real learner policy proof.
- Rollback: visual-only code revert or prior QA Worker version on blank frames, device crashes, p95 regressions, Cron >30 min failure, welfare/reward regressions or missing H6 markers. Never reset D1 learning history.
